# Driftwood

A landing page for a fictional product: a tiny desk device that turns your Spotify listening history into slowly growing physical coral.

Single self-contained `index.html` — HTML, CSS and vanilla JS, no external libraries or images.

Live: https://deepsad.github.io/driftwood/

Alternative version: https://deepsad.github.io/driftwood/gpt/ (`gpt/index.html`)

*Driftwood is fictional. Not affiliated with or endorsed by Spotify.*
